# CC Switch v3.20.0（S1）

> 本次是 product-upstream `farion1231/cc-switch` `v3.19.2..v3.20.0` 同步到 Web-first fork 的第一批。S1 落地文档、预设与 i18n 变更：在所有受支持应用中新增 PPIO、JieKou AI 与 XycAi 三个合作伙伴预设，在各语言加入 `xycai` 促销文案，将 RunAPI 预设域名迁移到 `runapi.host`（保留 `runapi.co` 作为回退端点），移除主面板供应商卡片上遗留的合作伙伴星标，并将版本号升到 3.20.0。独立 Web 服务部署模型、双运行时 parity 与既有 Web 安全加固保持不变；桌面 updater 仍保持禁用，未引入认证。

## 重点

- **新增合作伙伴预设**：PPIO、JieKou AI 与 XycAi 在 Claude Code、Codex、OpenCode、OpenClaw、Hermes（XycAi 另含 Gemini）中注册，各自带品牌图标，受支持的预设类型还附带端点回退。
- **RunAPI 域名迁移**：RunAPI 预设在六个应用中改以 `runapi.host` 为主域名，Claude Code、Codex、Grok Build 保留原 `runapi.co` 作为 `endpointCandidates` 回退。
- **更干净的主面板**：移除主面板供应商卡片上遗留的合作伙伴 ⭐ 徽标；合作伙伴星标只在预设选择器中显示，并从各语言删除不再使用的 `officialPartner` 翻译键。
- **版本升级**：`package.json`、`Cargo.toml`、`tauri.conf.json` 与 `Cargo.lock` 升至 `3.20.0`。

## Fork 专属偏差

- `zh-TW` 语言与 `README_DE` 不恢复；触及它们的上游 hunk 作为 no-op 丢弃。
- `claudeDesktopProviderPresets` 表面与 README 中桌面专属赞助商横幅表格继续排除，因此上游的桌面预设与 README 赞助商 hunk（FennoAI offer 更新）作为 no-op 丢弃。
- PPIO/JieKou Codex 预设上的 `codexChatReasoning` 字段**不在本批引入**——它属于后续批次的每模型 reasoning level 工作，fork 的 `CodexProviderPreset` 类型尚未承载该字段。

## 本批范围之外（后续批次）

v3.20.0 剩余同步工作——安全/数据完整性修复、定价/usage 种子、codex/provider 功能、UI/refactor、Windows 适配、CI 适配，以及三个全新大特性（Pi native agent、Codex Alpha WebSearch、managed OAuth accounts）——在后续批次 S2–S8 与各子任务中落地。
