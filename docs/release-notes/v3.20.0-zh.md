# CC Switch v3.20.0

> 本次将 product-upstream `farion1231/cc-switch` 的 `v3.19.2..v3.20.0` 通过选择性移植（selective port）同步到 Web-first fork，共分 7 个主题批次（S1–S7）。独立 Web 服务部署模型、双运行时 parity、无认证姿态、已禁用的桌面 updater 与既有 Web 安全加固全部保持不变。三个全新大特性（Pi native coding agent、Codex Alpha WebSearch、managed OAuth accounts）拆分为独立子任务，单独落地。

## 重点

- **S1 文档/预设/i18n**：在所有受支持应用中注册 PPIO、JieKou AI 与 XycAi 三个合作伙伴预设（含品牌图标，受支持的预设类型还附带端点回退）；RunAPI 预设迁移到 `runapi.host`（保留 `runapi.co` 作为回退端点）；移除主面板供应商卡片上遗留的合作伙伴 ⭐ 徽标（合作伙伴星标只在预设选择器中显示）；各语言加入 `xycai` 促销文案；版本号升到 3.20.0。
- **S2 安全/数据完整性**：env-check preflight 挂起修复；不再覆盖 Codex ChatGPT 登录（managed-OAuth 子任务的前置）；Kimi thinking 注入停止；zhipu `CREDIT_LIMIT` 配额；routing 动画激活；sync/restore 一致性（事务化 restore，每表 prepare-once INSERT）；backup SQL 保真度（多行 `VALUES` 批处理，trigger/index 顺序）。fork 的 canonical-schema allow-list、backup/replace 锁边界、2s JS deadline、16 MiB heap / 256 KiB stack 上限与 SQLite authorizer 严格性全部保留。
- **S3 定价/usage**：DeepSeek V4 peak + Gemini 3.7 Flash 种子；DeepSeek catalog 镜像抽取；Grok 4.5 cached + Grok 4.6 + DeepSeek alias；多年趋势 tooltip；DeepSeek cache-hit tokens。FE-preset ↔ Rust-seed 一致性门禁通过（无 `cost=$0`）。
- **S4 codex/provider**：移除 Goal 模式 toggle；恢复 1M context toggle；IME-safe provider 字段（新建共享 `ImeSafeInput`，Hermes/OpenClaw/OpenCode 表单采用）；取消过期 device login；Grok Build Codex 复制；grokbuild 表单对齐；macOS IME 损坏修复。`0455a92c` 多 follow-login 与 `897ca892` OAuth usage 拆分（前端增量落到父任务；Rust managed-codex 事务移交 managed-OAuth 子任务）。`40cac1a6` 每模型 reasoning levels 拆分（catalog 数据层落地；转换/UI 层延期）。
- **S5 UI/refactor**：Hermes/OpenCode/OpenClaw 表单层级对齐；checkbox 样式统一（Radix → 原生 `<input>`，保留 `onCheckedChange`/`checked` 契约）；OpenClaw 模型编辑器；model-dropdown 整合；fuzzy model dropdown（新建 fork 从未承载的共享 `ModelDropdown.tsx`）；Claude 高级选项对齐；缩减编辑器空白；GrokBuild glass 容器；skills `check_updates` 现在把缺失 SSOT 目录报告为 update。
- **S6 Windows**：消除启动 FOUC（anti-FOUC inline script + 主题化窗口背景 + CSP SHA-256）；Windows CLI 从注册表 PATH + 独立安装器目录检测（适配到 fork 的 `services/tool_version.rs`）；WiX Handlebars 反斜杠转义；WSL atomic-replace 回退（保留 fork 2s deadline + heap/stack 上限）。
- **S7 CI**：当 PR 既不触及前端也不触及后端时跳过对应检查（适配到 fork 的 3-job `frontend`/`backend`/`web-server` 结构，新增 `changes` job 使用 `dorny/paths-filter`，SHA-pinned）。
