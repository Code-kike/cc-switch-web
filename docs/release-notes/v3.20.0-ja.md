# CC Switch v3.20.0（S1）

> 今回は product-upstream `farion1231/cc-switch` の `v3.19.2..v3.20.0` を Web-first fork へ同期する第 1 バッチです。S1 ではドキュメント・プリセット・i18n の変更を取り込みます。対応する全アプリに PPIO・JieKou AI・XycAi の 3 つのパートナープリセットを追加し、各言語に `xycai` プロモーション文案を追加、RunAPI プリセットのドメインを `runapi.host` に移行（`runapi.co` をフォールバック端点として保持）、メインパネルのプロバイダーカードから旧式のパートナー星バッジを削除し、バージョンを 3.20.0 に引き上げます。スタンドアロン Web サーバーのデプロイモデル・デュアルランタイム parity・既存の Web セキュリティ強化は変更なし。デスクトップ updater は引き続き無効化し、認証は導入しません。

---

## ハイライト

- **新規パートナープリセット**：PPIO・JieKou AI・XycAi を Claude Code・Codex・OpenCode・OpenClaw・Hermes（XycAi は Gemini も）に登録。それぞれにブランドアイコンを割り当て、対応するプリセット型ではエンドポイントのフォールバックも保持します。
- **RunAPI ドメイン移行**：RunAPI プリセットは 6 アプリすべてで主ドメインを `runapi.host` に変更し、Claude Code・Codex・Grok Build では従来の `runapi.co` を `endpointCandidates` のフォールバックとして残します。
- **よりクリーンなメインパネル**：メインパネルのプロバイダーカードから旧式のパートナー ⭐ バッジを削除。パートナーの星はプリセットセレクタのみに表示し、不要になった `officialPartner` 翻訳キーを各言語から削除します。
- **バージョンアップ**：`package.json`・`Cargo.toml`・`tauri.conf.json`・`Cargo.lock` を `3.20.0` に引き上げます。

## Fork 固有の差異

- `zh-TW` ロケールと `README_DE` は復元しません。これらに触れる上流 hunk は no-op として破棄します。
- `claudeDesktopProviderPresets` の面と README のデスクトップ専用スポンサーバナー表は引き続き除外するため、上流のデスクトッププリセット・README スポンサー hunk（FennoAI オファー更新）は no-op として破棄します。
- PPIO/JieKou Codex プリセットの `codexChatReasoning` フィールドは**本バッチでは導入しません**。これは後続バッチの per-model reasoning level 作業に属し、fork の `CodexProviderPreset` 型はまだこのフィールドを持ちません。

## 本バッチの範囲外（後続バッチ）

v3.20.0 の残りの同期作業（セキュリティ/データ整合性修正、価格/usage シード、codex/provider 機能、UI/refactor、Windows 適応、CI 適応、および 3 つの大型新機能：Pi native agent・Codex Alpha WebSearch・managed OAuth accounts）は、後続バッチ S2–S8 と各サブタスクで取り込みます。
