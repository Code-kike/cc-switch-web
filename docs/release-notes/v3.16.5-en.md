# CC Switch v3.16.5

> Selected product-upstream `farion1231/cc-switch` v3.16.2..v3.16.5 changes ported into this Web-first fork, with Web server security and deployment behavior preserved.

---

## Overview

This release syncs the core runtime and user-facing product changes from product upstream `v3.16.2` through `v3.16.5` into the Web-first fork. It is not a blind desktop-source merge: Web-only server files, non-loopback auth requirements, SSRF protections, log privacy defaults, and proxy/failover hardening remain authoritative.

**Release date**: 2026-07-07

---

## Highlights

- **Schema v11 usage/pricing storage**: request, response, and pricing model dimensions are stored so usage rollups remain auditable after detail pruning.
- **Database compatibility guard**: Web server startup now refuses too-new databases before migration writes, and migration creates a local backup before changing existing DBs.
- **Codex native Responses catalog**: Codex provider live writes can generate a cc-switch-owned model catalog, and `/v1/models` serves it only while the live config still references that catalog.
- **Codex request/response compression**: the proxy now decodes supported `content-encoding` values, including zstd and stacked codings, for Codex request bodies and upstream response diagnostics.
- **Session organization**: the session manager adds grouped browsing and batch selection by provider and project directory.
- **Functional catalog refresh**: provider/preset/pricing updates that affect model availability, defaults, routing, or accounting were ported; sponsor/referral-only churn was left out.

---

## Web Adaptations

- Standalone Web server startup keeps the existing Web security boundary: `/api` auth, loopback/default bind protections, outbound URL guards, and privacy-by-default logging are preserved.
- Desktop updater, release packaging, Windows ARM64 release workflow, Linux desktop launch tweaks, and sponsor/marketing assets are intentionally excluded unless needed by Web runtime behavior.
- The full upstream Codex Chat Completions conversion stack remains deferred in this fork. The Web sync includes native Responses catalog support and Codex proxy error normalization needed by the current Web-managed flow.

---

## Upgrade Notes

- Existing databases are backed up before schema migration. If a database was written by a newer CC Switch schema, this version blocks startup and shows recovery guidance instead of attempting downgrade writes.
- Usage totals may change where prior rows lacked a separate pricing-model dimension; the new schema favors traceable request/response/pricing attribution.
- Codex-generated model catalogs are served only when the active `config.toml` points at cc-switch's catalog file, avoiding stale model lists after manual config changes.
