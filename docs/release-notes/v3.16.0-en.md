## Overview

CC Switch v3.16.0 ports the upstream `farion1231/cc-switch` v3.16.0 changes into this Web-first fork, continuing the granular `sync:` methodology. The headline change is **real-time usage statistics**: the usage dashboard now refreshes the moment new request logs are written (proxy logs, Claude / Codex / Gemini session sync, startup archival) instead of waiting for the polling cycle. Because this fork runs in two runtimes, the event is routed through the runtime-neutral `UiEventSink` abstraction — emitted over the Tauri event bus on desktop and over the `GET /api/events` SSE channel in web-server mode — so live refresh works in the browser too.

This release also hardens the shared backend: a Codex session-sync crash on non-ASCII model names (e.g. `【官】glm-5.1`) is fixed so the 60-second background sync timers no longer panic; DeepSeek's Anthropic-compatible tool-thinking history is normalized in the proxy; and deeplink imports of Claude providers now preserve custom environment variables passed via the inline config payload instead of dropping them.

On the configuration side, the model and pricing catalog is refreshed (default Claude Opus is bumped to 4.8, ShengSuanYun prefixed model IDs and GPT 5.5 are corrected, the OpenCode Go preset drops its model suffix, and OMO recommended models are refreshed with improved "Fill Recommended" feedback), with the Rust `seed_model_pricing` seed and the frontend presets kept consistent. Finally, the Codex routing layer is refactored to **stop force-rewriting the user's `model_provider` field** in live `config.toml`, aligning with upstream and preserving each provider's real `model_provider` id; a remote-compaction toggle is added for third-party Codex providers.

## Added

### Real-Time Usage Statistics Refresh

A new `usage-log-recorded` event is emitted whenever a new row is written to `proxy_request_logs` (proxy logs, Claude / Codex / Gemini session sync, startup archival). The frontend `useUsageEventBridge` hook — mounted on the usage dashboard — listens for it and invalidates the usage query namespace immediately, so figures update without waiting for the 30-second polling cycle.

The event is delivered through the runtime-neutral `event-adapter`: the Tauri event bus on desktop, and the `GET /api/events` SSE channel in web-server mode. Emission is debounced over a 200 ms window and only fires when a row was actually inserted (`INSERT OR IGNORE` skips do not produce empty refreshes), so a bulk session import that writes thousands of rows triggers only a couple of refresh events.

### Codex Remote Compaction Toggle

Third-party Codex providers gain a remote-compaction toggle in the provider editor.

## Changed

### Codex Live Config Preserves the Real `model_provider` Id

The fork previously force-rewrote the Codex live `config.toml` `model_provider` field to a stable internal `ccswitch` anchor bucket so that Codex resume history stayed grouped across provider switches. Upstream v3.16.0 removed force-rewriting (pairing it with a one-time Codex history migration the fork does not yet carry). This release **adopts the upstream behavior**: new writes preserve each provider's real `model_provider` id, and the custom routing key is unified to `custom`. See the Upgrade Notes for the behavior-change details.

### Model & Pricing Catalog Refresh

- Default Claude Opus upgraded to **4.8**.
- ShengSuanYun prefixed model IDs corrected; GPT 5.5 added.
- OpenCode Go preset renamed to drop the model suffix.
- OMO recommended models refreshed, with improved "Fill Recommended" feedback.
- Rust `database/schema.rs::seed_model_pricing` and the frontend `src/config/*Presets` kept consistent; an idempotent pricing-repair pass updates legacy rows that still carry old prices.

## Fixed

### Codex: Session-Sync Panic on Non-ASCII Model Names

`normalize_codex_model` previously sliced the last 11 bytes off the model name to strip an ISO date suffix without checking the slice fell on a UTF-8 character boundary. Non-ASCII model names (e.g. `【官】glm-5.1`) caused a panic that took down the fork's 60-second background session-sync timers. The slice is now guarded by `is_char_boundary` and an ASCII check on the suffix.

### Proxy: DeepSeek / Anthropic Tool-Thinking History Normalization

The proxy now normalizes DeepSeek's Anthropic-compatible tool thinking history, improving correctness for server-mode Claude-compatible / DeepSeek routing.

### Deeplink: Custom Env Fields Preserved on Claude Provider Import

Importing a Claude provider via deeplink now starts from the full `env` block in the inline base64 config (when present) and merges the standard URL-param fields on top, so custom environment variables the user passed survive the import.

### About: Prerelease-Aware Tool Version Comparison

Tool "update available" detection now uses a lightweight semver comparison (`src/lib/version.ts`) instead of a string `!==`. Locally installed prerelease/next-channel CLI versions that are *ahead* of the published `latest` no longer trigger a permanent false "update available" prompt.

## ⚠️ Upgrade Notes

### Codex `model_provider` Anchor Removed

Earlier fork builds rewrote the Codex live `config.toml` `model_provider` to a stable internal `ccswitch` bucket so that Codex resume history stayed grouped across CC Switch provider switches. This release removes that anchor to align with upstream: new Codex live writes now use each provider's **real** `model_provider` id. As a result, existing fork users' Codex resume-history bucket key may change after upgrading (desktop-only, narrow impact). The upstream one-time Codex history-continuity migration is **deferred** to a follow-up task; if continuity matters to you, hold the relevant Codex sessions until that migration ships.
